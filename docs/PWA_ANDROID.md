# Trafinexo Android/PWA

Release consolidado conforme o padrão INFOTEC de 02/09/2026.

- responsivo em desktop, tablet e celular;
- manifesto PWA;
- ícones 192/512;
- modo standalone;
- start URL operacional;
- service worker restrito ao shell/arquivos estáticos;
- APIs, Supabase e dados transacionais fora do cache;
- opção visível de instalação no Android;
- fallback de instalação pelo Chrome;
- safe-area e experiência mobile na mesma base de código.
